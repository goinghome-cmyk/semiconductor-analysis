# 반도체 산업 분석 앱

국내 상장 반도체 기업 9곳의 **DART 공시·재무제표, 한국은행 통계, 뉴스**를 엮어서
**① 업황이 어디쯤인지**와 **② 각 기업의 숫자를 믿을 수 있는지**를 함께 보는 Streamlit 앱입니다.

> 자료를 한곳에 모아 보여주는 데서 그치지 않고, **한 자료에서 생긴 질문을 다른 자료가 답하도록** 연결하는 데 초점을 뒀습니다.

## 자료를 엮어서 찾아낸 것 (예시)

| 연결한 자료 | 앱이 보여준 것 |
|---|---|
| 재무제표 × 공시 × 뉴스 | 동진쎄미켐 2025년 3분기에 **공시된 3개월 매출과 누적 매출이 맞지 않는 분기**를 감지 → 그 분기 보고서 원문에서 "중국 종속법인 10개 매각 계약", 같은 시기 공시에서 "타법인주식처분결정·회사분할결정"을 찾아 **중단영업 재분류에 따른 과거 실적 재작성**임을 추적 |
| 재무제표 × 현금흐름 × 감사보고서 | 원익IPS: 이익의 현금 전환 0.35배, 매출채권 회수일수 2배 증가, 그리고 감사인의 핵심감사사항이 **"장비매출의 발생사실"** → 세 자료가 같은 곳을 가리킴 |
| 감사보고서 × 재무제표 주석 | 이오테크닉스: 감사인의 핵심감사사항이 **"매출채권 손실충당금"·"재고자산평가충당금"** → 주석에서 뽑은 숫자로 확인하면 매출채권의 16.8%를 이미 손실 처리, 재고 평가충당금 비율은 1년 새 10.9% → 16.9% |
| 손익계산서 × 주석 | SK하이닉스: 재고 평가충당금이 1년 새 6,617억 줄어(8.0% → 3.3%) 과거 손실이 이익으로 되돌아온 부분이 있고, 세전이익의 38%가 영업 밖에서 나옴 |
| 사업 형태 × 재무상태표 × 사업보고서 | 같은 원익IPS의 재고 증가는 **선수금 +22%, 수주잔고 +221%**와 함께 늘어 '주문 대응'으로 판정 (장비는 수주산업이라 재고를 다르게 봄) |
| 사업보고서 주석 × 산업 집계 | 삼성전자는 스마트폰·가전이 섞여 있어, 주석의 '부문별 보고'에서 **반도체(DS) 부문 실적만** 뽑아 산업 집계에 사용 |
| 한국은행 통계 × 기업 실적 | 메모리 가격이 10%p 더 오를 때 삼성전자 DS 매출 성장률은 약 +15%p, SK하이닉스는 약 +9%p 더 오르는 경향 (업황 민감도) |

## 기능

| 페이지 | 내용 |
|---|---|
| 🏠 홈 | 데이터에서 뽑은 '지금 한눈에' 요약, 데이터 기준일, 페이지 안내 |
| 🏭 산업 대시보드 | ① 사이클 국면 신호등 ② 한국은행 선행지표(메모리 수출물가, 반도체 가동률·생산능력, 출하-재고 순환, 환율) ③ 밸류체인 흐름(칩메이커 설비투자 → 장비 매출) ④ 이익 집중도·그룹별 비교 ⑤ 업황 민감도 ⑥ 기업별 상세 |
| 📋 종합 진단 | 산업·성장·수익성·밸류에이션·업황 민감도·현금흐름·이익의 질·감사·이상치를 한 장의 체크리스트로 |
| 🔎 기업 분석 | 밸류에이션(같은 밸류체인 그룹 대비), 분기 실적, 삼성전자 DS 부문, 현금흐름 8유형, 가동률, 감사의견 |
| 🧪 이익의 질 | 현금 전환(1년·3년 누적), 본업 밖 이익 비중, 잉여현금흐름, 재고·매출채권 일수, **주석에서 뽑은 재고 평가충당금·매출채권 충당금**, 수주 동향, 실적 재작성 + 감사 핵심감사사항 ↔ 관련 수치 ↔ 주석 |
| 🔍 이상치 추적 | 급변 분기 감지 → 그 분기 보고서 문단 · 같은 시기 공시 · 뉴스 · 업계 흐름으로 원인 단서 수집 |
| 📑 사업·감사보고서 | 사업의 내용, 경영진단, 감사의견, 재무제표 주석을 표·문단 구조 그대로 읽기 쉽게 |
| 📰 뉴스 · 📘 지표 설명 | 기간별 뉴스 검색, 모든 판정 기준·계산식·용어 사전 |

모든 ✅⚠️🔴 판정은 **규칙 기반**이고, 기준은 각 페이지와 '지표 설명'에 공개되어 있습니다.

## 만들면서 푼 문제

- **DART 과다 호출 차단 방지**: 요청을 1초 간격으로 순차 처리하고, 일일 상한(로컬 3,000건 / 공개 500건)을 두고, 제한 응답을 받으면 1시간 동안 호출을 멈춥니다. 과거 보고서는 영구 캐시하고, 캐시를 저장소에 함께 올려 클라우드 재시작에도 재호출하지 않습니다.
- **분기 실적 계산 오류**: 누적값의 차이로 분기를 구하면, 회사가 과거 기간을 재작성했을 때 틀린 값이 나옵니다. 공시된 3개월 값을 우선 쓰고, 둘이 어긋나면 '재작성' 신호로 활용합니다.
- **공시 원문 가독성**: DART 원문은 문단까지 테두리 없는 표로 되어 있고 머리글이 여러 단으로 병합돼 있습니다. 표 격자를 펼치고 머리글을 합쳐 문단/표로 재구성했습니다.
- **보고서마다 다른 형식**: 삼성전자 부문별 보고(4가지 형식), 수주잔고 표(두 줄 머리글, 미공시), 가동률(시간 기준·수량 기준·여러 표, '가동율' 표기)을 각각 처리합니다.
- **사업 형태별 해석**: 계획생산(메모리)·주문생산(파운드리)·수주산업(장비)·반복공급(소재)에 따라 재고의 의미를 다르게 판정합니다.
- **공정한 비교**: 이익의 99%가 두 회사에 몰려 있어 전체 평균 대신 밸류체인 그룹별로, 기업 페이지와 종합 진단은 **자기 자신을 뺀 경쟁사 평균**과 비교합니다(그룹이 3곳 안팎이라 중앙값은 한 회사 값이 되어 버림).

## 한계

- 기업 데이터가 약 3년(분기 10~14개)이라 사이클 한 바퀴를 다 담지 못하고, 업황 민감도의 표본도 작습니다.
- 판정 기준값(2%p, 15% 등)은 설계자가 정한 것이며 업계 표준 공식이 아닙니다.
- 한국은행 출하·재고 지수는 반도체 단독이 아닌 전자부품 업종 전체 지수입니다.
- 공시된 메모리 가동률은 '시간 기준'이라 거의 늘 100%입니다. 감산 여부는 업계 가동률지수로 대신 봅니다.

## 실행

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

`.streamlit/secrets.toml` (`secrets.toml.example` 참고):

```toml
DART_API_KEY = "발급받은 키"     # 필수 (opendart.fss.or.kr)
ECOS_API_KEY = "발급받은 키"     # 선택. 없으면 한국은행 지표 관련 기능만 빠짐
ANTHROPIC_API_KEY = ""           # 선택. 비우면 AI 요약만 꺼짐
# PUBLIC_MODE = "true"           # 다른 사람에게 보여줄 배포용 (아래 참고)
# FEEDBACK_URL = "https://..."   # 하단 '의견 보내기' 링크 (구글 폼, GitHub 이슈 등)
```

- 데이터 갱신·예열: `python scripts/refresh_data.py` (앱이 쓰는 자료를 미리 캐시에 받아 둠)
- 연결 점검: `python scripts/check_dart.py 000660`

## 배포 (Streamlit Community Cloud, 초대한 사람만)

1. 이 폴더를 GitHub 저장소로 올립니다. `secrets.toml`은 `.gitignore`에 있어 올라가지 않고, `data/cache/`(공시 캐시)는 함께 올라갑니다.
2. https://share.streamlit.io → **Create app** → 저장소와 `app.py` 선택.
3. **Advanced settings → Secrets**에 키와 `PUBLIC_MODE = "true"`를 넣고 Deploy.
   공개 모드에서는 저작권 자료인 증권사 리포트 페이지가 빠지고(주소로도 열리지 않음), 개발용 표시가 숨겨지며, DART 일일 상한이 500건으로 낮아집니다.
4. 앱 **Settings → Sharing**에서 "Only specific people can view this app"을 고르고 이메일로 초대합니다.

## 다른 산업 추가

`config/semiconductor.json`을 복사해 기업 목록·밸류체인 그룹·사업 형태·한국은행 지표 코드를 바꾸면 사이드바 '산업' 선택에 나타납니다.
금융업은 재무제표 양식과 핵심 지표(NIM, 대손비용률 등)가 달라 `src/metrics.py`의 계정 매핑을 따로 손봐야 합니다.
